# YCopyPaste

Менеджер буфера обмена для macOS. Живёт в строке меню, запоминает всё, что вы копируете, и позволяет быстро найти и вставить любой прошлый фрагмент.

## Возможности

- **История буфера**: текст, ссылки, форматированный текст (RTF/HTML), картинки и файлы. Повторы не дублируются: элемент просто поднимается наверх.
- **Окно истории по ⇧⌘V** открывается там, где вы его оставили: перетащите окно за панель поиска, и оно запомнит место: стрелки для выбора, Enter вставляет, ⌘1…⌘9 вставляют элемент по номеру.
- **Мгновенный нечёткий поиск**: просто начните печатать. «gtcm» найдёт «git commit».
- **Предпросмотр** длинного текста, картинок и списка файлов справа, с приложением-источником и временем копирования.
- **Режим листания (⌃⌘V)**: держите ⌃⌘ и нажимайте V, чтобы листать историю; отпустите клавиши, и элемент вставится.
- **Закреплённые элементы** (⌘P): шаблоны, адреса, реквизиты. Не удаляются при очистке и по лимитам. Tab переключает список на закреплённые.
- **Вставка без форматирования** (⌥Enter) и «только скопировать» (⌘Enter).
- **Приватность**: пароли из менеджеров паролей не сохраняются; есть чёрный список приложений (Связка ключей, 1Password, Bitwarden и др.), пауза записи и очистка истории.
- **Только локально**: история в SQLite на вашем Mac, никакой сети. Лимит по количеству (по умолчанию 1000) и по сроку хранения.
- Запуск при входе в систему, без иконки в Dock.

## Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Везде | ⇧⌘V | Открыть/закрыть историю |
| Везде | ⌃⌘V (держать) | Режим листания: листать и вставить |
| В окне | ↑ ↓ | Выбор |
| В окне | ↩ | Вставить |
| В окне | ⌥↩ | Вставить без форматирования |
| В окне | ⌘↩ | Только скопировать в буфер |
| В окне | ⌘1 … ⌘9 | Вставить элемент по номеру |
| В окне | ⌘P | Закрепить / открепить |
| В окне | ⌘⌫ | Удалить из истории |
| В окне | ⇥ | Все / Закреплённые |
| В окне | ⎋ | Очистить поиск / закрыть |
| В окне | ⌘, | Настройки |

Глобальные сочетания меняются в **Настройки → Клавиши**.

## Установка

Нужен macOS 13 Ventura или новее.

### Способ 1. Скачать готовое приложение (проще всего)

1. Откройте на GitHub вкладку **Actions** → последний зелёный запуск **Build** → внизу раздел **Artifacts** → скачайте **YCopyPaste**. (Если есть вкладка **Releases**, можно скачать `YCopyPaste.zip` оттуда.)
2. Распакуйте архив и перетащите **YCopyPaste.app** в папку **Программы** (Applications).
3. Первый запуск: приложение не подписано сертификатом Apple, поэтому macOS его заблокирует. Откройте **Терминал** и выполните одну команду:
   ```bash
   xattr -dr com.apple.quarantine /Applications/YCopyPaste.app
   ```
   Затем запустите YCopyPaste из Программ. (Другой вариант: попробовать открыть, затем **Системные настройки → Конфиденциальность и безопасность** → внизу кнопка **«Всё равно открыть»**.)

### Способ 2. Собрать на своём Mac

1. Установите инструменты разработчика Apple (один раз, бесплатно). В Терминале:
   ```bash
   xcode-select --install
   ```
   Появится окно, нажмите «Установить» и дождитесь окончания (несколько минут). Полный Xcode не нужен.
2. Скачайте проект: на странице репозитория **Code → Download ZIP** и распакуйте, или:
   ```bash
   git clone https://github.com/igoryakus/YCopyPaste.git
   ```
3. Перейдите в папку проекта и запустите сборку с установкой:
   ```bash
   cd YCopyPaste
   ./scripts/build-app.sh --install
   ```
   Скрипт соберёт `build/YCopyPaste.app`, скопирует его в **Программы** и запустит. Первая сборка занимает 1–3 минуты.

### После первого запуска: разрешить автовставку

Чтобы выбранный элемент сам вставлялся в нужное место (а не только копировался), YCopyPaste должен «нажать» ⌘V за вас. Для этого macOS требует разрешение:

1. **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
2. Включите переключатель у **YCopyPaste** (если его нет в списке, нажмите «+» и выберите приложение в Программах).

Приложение само предложит это при первом запуске. Статус виден в **Настройки → Основные**.

**Включите «Запускать при входе в систему»** в настройках, чтобы история работала всегда.

## Обновление

Соберите или скачайте новую версию и замените приложение в Программах (`./scripts/build-app.sh --install` делает это сам).

> ⚠️ После каждой пересборки macOS считает приложение «новым» и автовставка может перестать работать. Тогда откройте **Универсальный доступ**, удалите YCopyPaste кнопкой «−» и добавьте заново (или выключите и включите переключатель).

## Где хранятся данные

`~/Library/Application Support/YCopyPaste/history.sqlite`. Чтобы полностью сбросить историю, закройте приложение и удалите эту папку.

## Частые вопросы

- **Элемент не вставляется, а только копируется.** Не выдано разрешение «Универсальный доступ» (см. выше) или выключена опция «Вставлять сразу после выбора».
- **⇧⌘V не работает.** Это сочетание может быть занято другой программой. Задайте другое в **Настройки → Клавиши**.
- **Пароль из 1Password попал в историю.** Проверьте, что включено «Не сохранять пароли и скрытые данные», или добавьте приложение в чёрный список в **Настройки → Приватность**.

## Разработка

```bash
swift build          # отладочная сборка
open Package.swift   # открыть в Xcode
```

Структура `Sources/YCopyPaste`:

- `App/` — запуск, связка компонентов, меню в строке меню
- `Clipboard/` — слежение за буфером, определение типа, вставка (⌘V через CGEvent)
- `Storage/` — SQLite и модель истории
- `Hotkeys/` — глобальные горячие клавиши (Carbon)
- `UI/` — окно истории, поиск, режим листания
- `Settings/` — настройки
